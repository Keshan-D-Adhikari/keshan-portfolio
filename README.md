# Keshan Adhikari: Portfolio

**Live:** https://keshan-adhikari.vercel.app

Personal portfolio site built with **Next.js 15**, **TypeScript** and **Tailwind CSS 4**. One page with About, Skills, Projects, Education & leadership, and Contact sections, in both light and dark themes.

## Edit the content

All text, projects, skills and links are in [`src/data/portfolio.ts`](src/data/portfolio.ts). Project screenshots go in `public/projects/`.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy

The repo is connected to Vercel, so every push to `main` deploys to production automatically.
